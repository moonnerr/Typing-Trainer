### 1. Введение

В современном мире навыки быстрой и грамотной печати на клавиатуре являются важной составляющей эффективной работы за компьютером. Они позволяют экономить время при написании текстов, программировании, общении и выполнении повседневных задач.

Однако для развития навыка слепой печати необходимы регулярные тренировки и возможность отслеживать собственный прогресс.

В рамках итогового проекта второго курса Яндекс Лицея разрабатывается приложение **TypingTrainer**, предназначенное для тренировки скорости и точности набора текста на клавиатуре.

### 2. Цель проекта

Разработать настольное приложение, позволяющее пользователю тренировать скорость и точность печати, а также отслеживать результаты своих тренировок.

### 3. Задачи проекта

Для достижения поставленной цели необходимо решить следующие задачи:

1. Изучить возможности библиотеки PyQt6 для создания графического интерфейса.
2. Разработать структуру базы данных для хранения тренировочных текстов и результатов.
3. Реализовать загрузку случайных текстов в зависимости от выбранного уровня сложности.
4. Разработать механизм проверки вводимых пользователем символов.
5. Реализовать подсчёт скорости печати, точности и количества ошибок.
6. Добавить таймер для измерения продолжительности тренировки.
7. Разработать систему сохранения результатов.
8. Реализовать отображение статистики и графика прогресса.
9. Предусмотреть возможность переключения языков и оформления интерфейса.

### 4. Описание приложения

TypingTrainer представляет собой настольное приложение с графическим интерфейсом, разработанное на языке программирования Python.

Основная задача пользователя — набирать предложенный приложением текст, стараясь делать это максимально быстро и без ошибок.

В приложении предусмотрены три уровня сложности:

- Лёгкий.
- Средний.
- Сложный.

В зависимости от выбранного уровня пользователю предлагаются тексты различной длины и сложности.

Также планируется поддержка двух языков тренировочных текстов: русского и английского. Язык интерфейса будет настраиваться независимо от языка тренировочного текста.

### 5. Используемые технологии

При разработке проекта используются следующие инструменты и технологии:

- **Python** — основной язык программирования.
- **PyQt6** — библиотека для создания графического интерфейса.
- **SQLite** — система управления базами данных для хранения тренировочных текстов и результатов.
- **Matplotlib** — библиотека для построения графиков и визуализации прогресса.

### 6. Основные функциональные возможности

В приложении предусматриваются следующие функции:

**Проверка правильности ввода.**
Приложение проверяет каждый введённый символ и сравнивает его с соответствующим символом тренировочного текста. Переход к следующему символу возможен только после правильного ввода текущего.

**Подсчёт ошибок.**
При неправильном вводе символа увеличивается счётчик ошибок.

**Расчёт точности.**
Точность определяется на основе количества правильно введённых символов и допущенных ошибок.

**Измерение времени.**
Время тренировки начинает отсчитываться после ввода первого символа.

**Расчёт скорости печати.**
Скорость измеряется в символах в минуту (CPM — Characters Per Minute).

**Статистика и прогресс.**
Предусматривается сохранение результатов тренировок и отображение изменений скорости печати с помощью графика.

**Настройки интерфейса.**
Планируется реализация переключения светлой и тёмной темы, а также выбора языка интерфейса.

### 7. Текущий этап разработки

На момент подготовки данной пояснительной записки реализована основная часть механики тренировки:

- Создано основное окно приложения с использованием PyQt6.
- Реализована загрузка случайных текстов из базы данных SQLite.
- Добавлено переключение между уровнями сложности.
- Реализована посимвольная проверка вводимого текста.
- Добавлена визуальная индикация правильного и неправильного ввода.
- Реализован подсчёт ошибок и расчёт точности.
- Добавлен таймер тренировки.
- Реализован расчёт текущей скорости печати в символах в минуту.

В дальнейшем планируется завершить работу над сохранением результатов тренировок, статистикой, графиком прогресса, настройками языков и тем оформления.

### 8. Ожидаемый результат

Результатом проекта должно стать полноценное настольное приложение TypingTrainer, предоставляющее пользователю удобный инструмент для регулярной тренировки навыков печати.

Приложение позволит оценивать собственную скорость и точность, анализировать результаты предыдущих тренировок и наблюдать за личным прогрессом.
