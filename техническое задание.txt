ТЕХНИЧЕСКОЕ ЗАДАНИЕ

Проект «TypingTrainer»


1. ОБЩАЯ ИНФОРМАЦИЯ

Название проекта: TypingTrainer.

Тип проекта: настольное приложение для тренировки скорости и точности набора текста на клавиатуре.

Язык программирования: Python.

Используемые технологии и библиотеки:
- PyQt6 — создание графического интерфейса;
- SQLite — хранение текстов, пользовательских настроек и результатов тренировок;
- Matplotlib — построение графика прогресса;
- time и QTimer — измерение времени тренировки;
- pathlib — работа с путями к файлам;
- sys — работа с запуском приложения.


2. ЦЕЛЬ ПРОЕКТА

Разработать настольное приложение, позволяющее пользователю тренировать скорость и точность печати, отслеживать собственные результаты и наблюдать за изменением скорости набора текста с течением времени.

Приложение должно иметь удобный графический интерфейс, поддерживать русский и английский языки, предоставлять возможность настройки внешнего вида и сохранять результаты тренировок между запусками программы.


3. ОСНОВНОЙ ФУНКЦИОНАЛ

3.1. Выбор тренировочного текста

- Тексты для тренировок хранятся в базе данных SQLite.
- Каждый текст имеет определённый уровень сложности и язык.
- Приложение поддерживает два языка тренировочных текстов: русский и английский.
- При загрузке тренировки приложение случайным образом выбирает текст из базы данных с учётом выбранного языка и уровня сложности.
- Пользователь может менять язык тренировочного текста независимо от языка интерфейса.
- При отсутствии текстов для выбранной комбинации языка и сложности приложение сообщает об этом пользователю.

3.2. Уровни сложности

В приложении предусмотрено три уровня сложности:
- Лёгкий (Light);
- Средний (Medium);
- Сложный (Hard).

Каждый текст в базе данных относится к одному из этих уровней.

Пользователь может самостоятельно переключаться между уровнями сложности. При выборе нового уровня приложение загружает случайный текст соответствующей категории.

3.3. Механика тренировки

- На экране отображается текст, который необходимо набрать.
- Пользователь вводит текст с помощью клавиатуры.
- Проверка введённых символов выполняется последовательно, символ за символом.
- Регистр символов учитывается: заглавные и строчные буквы считаются разными символами.
- При правильном вводе программа переходит к следующему символу.
- При неправильном вводе позиция не изменяется, и пользователь должен повторно ввести текущий символ правильно.
- Каждая ошибка учитывается в статистике.
- Нажатия клавиш, не вводящих текстовые символы, не засчитываются как ошибки.
- Правильно введённые символы выделяются зелёным цветом.
- Текущий символ визуально выделяется. При правильном последнем вводе его фон становится зелёным, при неправильном — красным.
- После ввода последнего символа тренировка автоматически завершается.

3.4. Переход к следующей тренировке

- Пользователь может перейти к следующему тексту с помощью кнопки «Следующий текст».
- При переходе загружается новый случайный текст с сохранением текущего уровня сложности и выбранного языка.
- При загрузке нового текста показатели текущей тренировки сбрасываются.
- Если предыдущая тренировка завершилась, но её результат не удалось сохранить, приложение предпринимает повторную попытку сохранения перед загрузкой следующего текста.


4. ПОДСЧЁТ СТАТИСТИКИ

Во время тренировки приложение рассчитывает и отображает три основных показателя.

Скорость печати (CPM):

- Измеряется в символах в минуту.
- Рассчитывается на основе количества правильно введённых символов и времени тренировки.
- Обновляется во время тренировки.
- Итоговое значение рассчитывается после завершения набора текста.

Точность печати:

- Отображается в процентах.
- Рассчитывается как отношение количества правильно введённых символов к общему количеству попыток ввода.
- Обновляется после каждого введённого символа.

Время тренировки:

- Отображается в формате минут и секунд.
- Отсчёт начинается после первого нажатия клавиши, вводящего символ.
- Обновляется во время тренировки.
- Итоговое время сохраняется после завершения тренировки.


5. ПАУЗА

- Приложение предоставляет возможность приостановить тренировку и продолжить её позже.
- Кнопка паузы становится доступной после начала ввода текста.
- Во время паузы таймер останавливается, а ввод символов не обрабатывается.
- При продолжении тренировки отсчёт времени возобновляется.
- Время, проведённое на паузе, не учитывается в общей продолжительности тренировки.


6. НАСТРОЙКИ ПРИЛОЖЕНИЯ

6.1. Язык интерфейса

- Приложение поддерживает русский и английский языки интерфейса.
- Пользователь может переключать язык с помощью отдельных кнопок.
- Переключение языка интерфейса не влияет на язык тренировочного текста.
- Выбранный язык интерфейса сохраняется в базе данных.

6.2. Язык тренировочного текста

- Пользователь может отдельно выбирать русский или английский язык текстов для набора.
- Изменение языка тренировочного текста приводит к загрузке нового текста.
- Выбранный язык сохраняется в базе данных.

6.3. Тема оформления

Приложение поддерживает две темы оформления:
- Светлая;
- Тёмная.

Пользователь может переключаться между ними с помощью соответствующей кнопки.

Выбранная тема применяется к интерфейсу и графику прогресса и сохраняется в базе данных.

6.4. Размер тренировочного текста

- Пользователь может изменять размер отображаемого тренировочного текста с помощью горизонтального ползунка.
- Доступный диапазон размера шрифта — от 12 до 36 пикселей.
- Текущее значение размера отображается в интерфейсе.
- Выбранный размер сохраняется в базе данных.


7. ХРАНЕНИЕ ДАННЫХ

Для хранения информации используется реляционная база данных SQLite.

В базе данных предусмотрены следующие таблицы.

7.1. Таблица texts

Содержит тексты, используемые во время тренировок.

Основные поля:
- id — уникальный идентификатор текста;
- content — содержимое текста;
- level — уровень сложности;
- language — язык текста.

7.2. Таблица results

Содержит результаты завершённых тренировок.

Основные поля:
- speed — скорость печати в символах в минуту;
- accuracy — точность печати;
- errors — количество допущенных ошибок;
- duration — продолжительность тренировки;
- level — уровень сложности;
- training_number — порядковый номер тренировки.

После завершения тренировки её результат сохраняется в базе данных.

Если сохранить результат не удаётся, приложение сообщает об ошибке. Результат временно остаётся в памяти программы, и при следующей попытке перехода к новому тексту выполняется повторная попытка сохранения.

7.3. Таблица settings

Содержит пользовательские настройки приложения.

Основные поля:
- id — идентификатор записи настроек;
- theme — выбранная тема оформления;
- font_size — размер тренировочного текста;
- interface_language — язык интерфейса;
- training_language — язык тренировочного текста.

При запуске приложения настройки загружаются из базы данных. Если запись с настройками отсутствует или отдельные значения некорректны, для них используются значения по умолчанию.


8. ГРАФИК ПРОГРЕССА

Для визуального отображения результатов используется библиотека Matplotlib.

График:
- отображает скорость печати в зависимости от номера тренировки;
- строится на основе сохранённых в базе данных результатов;
- обновляется после сохранения нового результата;
- учитывает выбранную тему оформления;
- содержит подписи осей и заголовок на выбранном языке интерфейса;
- отображает значения скорости печати в символах в минуту.

График позволяет пользователю отслеживать изменение скорости набора текста на протяжении нескольких тренировок.


9. ГРАФИЧЕСКИЙ ИНТЕРФЕЙС

Главное окно приложения разделено на три основные панели.

Левая панель:
- переключение языка интерфейса;
- название приложения;
- переключение темы оформления;
- выбор языка тренировочного текста;
- выбор уровня сложности.

Центральная панель:
- отображение текста для набора;
- визуальное выделение текущего и правильно введённых символов.

Правая панель:
- кнопка паузы и продолжения тренировки;
- кнопка перехода к следующему тексту;
- настройка размера тренировочного текста;
- отображение скорости печати, точности и времени;
- график прогресса.

Для оформления интерфейса используются отдельные стили, вынесенные в модуль styles.py.


10. ОБРАБОТКА ОШИБОК

Приложение предусматривает обработку ошибок, связанных с работой базы данных.

В частности:
- при невозможности загрузить настройки выводится сообщение об ошибке;
- при невозможности загрузить тренировочный текст выводится сообщение об ошибке;
- при отсутствии подходящих текстов выводится предупреждение;
- при невозможности загрузить статистику выводится предупреждение;
- при невозможности сохранить результат тренировки выводится предупреждение, а результат остаётся в памяти для повторной попытки сохранения;
- при невозможности сохранить отдельные настройки выводится соответствующее сообщение об ошибке.

Для информирования пользователя используются диалоговые окна QMessageBox.


11. ТРЕБОВАНИЯ К ПРОГРАММНОМУ ОБЕСПЕЧЕНИЮ

- Приложение должно быть реализовано на языке Python.
- Графический интерфейс должен быть создан с использованием PyQt6.
- Для хранения данных должна использоваться SQLite.
- Для построения графиков должна использоваться Matplotlib.
- Код оформления интерфейса должен находиться в отдельном модуле styles.py.
- Приложение должно сохранять пользовательские настройки и результаты тренировок между запусками.
- База данных должна находиться в рабочей директории приложения.


12. ОЖИДАЕМЫЙ РЕЗУЛЬТАТ

Результатом выполнения проекта является готовое настольное приложение TypingTrainer, позволяющее пользователю тренировать скорость и точность печати на русском и английском языках, выбирать уровень сложности, настраивать интерфейс, приостанавливать тренировки, сохранять результаты и отслеживать собственный прогресс с помощью графика.
