Техническое задание

Разработка приложения TypingTrainer

1. Общая информация о проекте

Название: TypingTrainer

Тип проекта: настольное приложение-тренажёр скорости печати.

Язык программирования: Python.

Используемые технологии и библиотеки:

- PyQt6 — создание графического интерфейса.
- SQLite — хранение текстов для тренировок и результатов пользователей.
- Python Standard Library — реализация основной логики приложения.

Цель проекта:

Разработать настольное приложение, позволяющее пользователю тренировать скорость и точность печати на клавиатуре, выбирать сложность и язык тренировочных текстов, отслеживать собственный прогресс и просматривать результаты предыдущих тренировок.


2. Основные функциональные возможности

Приложение должно предоставлять следующие возможности:

1. Выбор сложности тренировочного текста.
2. Выбор языка тренировочного текста.
3. Переключение языка интерфейса.
4. Случайная выдача тренировочного текста из базы данных.
5. Посимвольный ввод текста с проверкой правильности введённых символов.
6. Подсчёт скорости печати.
7. Подсчёт количества ошибок.
8. Сохранение результатов тренировок.
9. Просмотр статистики.
10. Отображение графика прогресса.
11. Переключение светлой и тёмной темы.
12. Раздел с информацией о приложении.


3. Графический интерфейс

Главное окно приложения должно состоять из трёх основных панелей.

3.1. Левая панель — навигация и настройки тренировки

Должна содержать:

- Название приложения TypingTrainer.
- Кнопку «Тренировка».
- Кнопку «Статистика».
- Кнопку «Настройки».
- Кнопку «О программе».
- Блок выбора сложности.
- Блок выбора языка тренировочного текста.

Для выбора сложности должны быть предусмотрены три кнопки:

- Light — лёгкая сложность.
- Medium — средняя сложность.
- Hard — высокая сложность.

При выборе сложности приложение должно загружать случайный текст соответствующего уровня.

3.2. Центральная панель — тренировка

Должна содержать:

- Текст, который необходимо напечатать.
- Поле для ввода текста.
- Таймер тренировки.
- Отображение текущей скорости печати.
- Отображение количества ошибок.
- Кнопку для получения нового текста.

Тренировочный текст должен отображаться отдельно от поля ввода.

3.3. Правая панель — статистика

Должна содержать:

- Текущую скорость печати.
- Количество ошибок.
- Результаты предыдущих тренировок.
- График изменения скорости печати.


4. Работа с базой данных

Для хранения информации использовать SQLite.

Создать базу данных "typing_trainer.db".

4.1. Таблица texts

Таблица предназначена для хранения тренировочных текстов.

Предусмотреть следующие поля:

- "id" — уникальный идентификатор текста, INTEGER PRIMARY KEY AUTOINCREMENT.
- "content" — содержание тренировочного текста, TEXT NOT NULL.
- "level" — уровень сложности, TEXT NOT NULL.
- "language" — язык тренировочного текста, TEXT NOT NULL.

Допустимые значения поля "level":

- light
- medium
- hard

Допустимые значения поля "language":

- ru
- en

В базе должны храниться тренировочные тексты на русском и английском языках.

На начальном этапе необходимо предусмотреть не менее 33 текстов для каждого уровня сложности на каждом языке.

4.2. Таблица results

Таблица предназначена для сохранения результатов тренировок.

Предусмотреть следующие поля:

- "id" — уникальный идентификатор результата.
- "speed" — скорость печати в символах в минуту.
- "errors" — количество ошибок.
- "level" — уровень сложности тренировки.
- "language" — язык тренировочного текста.
- "date" — дата и время завершения тренировки.

4.3. Работа с SQL

Для взаимодействия с базой данных использовать библиотеку sqlite3.

Реализовать:

- Подключение к базе данных.
- Создание курсора.
- Выполнение SQL-запросов.
- Получение тренировочного текста.
- Сохранение результатов.
- Закрытие подключения после выполнения операций.

Все параметры SQL-запросов передавать через параметризованные запросы.


5. Выбор и загрузка тренировочного текста

Создать метод "load_text()".

Метод должен принимать параметры:
- Уровень сложности.
- Язык тренировочного текста.

Алгоритм работы:

1. Подключиться к базе данных.
2. Создать курсор.
3. Выполнить SQL-запрос для поиска текстов с подходящими уровнем сложности и языком.
4. Случайным образом выбрать одну запись.
5. Получить содержание выбранного текста.
6. Сохранить его в атрибуте текущего объекта.
7. Отобразить текст в графическом интерфейсе.
8. Закрыть подключение к базе данных.

При отсутствии подходящих текстов необходимо вывести соответствующее сообщение.


6. Механика печати

Это основная функциональная часть приложения.

Необходимо реализовать строгую посимвольную проверку ввода.

Алгоритм работы:

1. Пользователь получает тренировочный текст.
2. Начинает вводить его в специальное поле.
3. Приложение сравнивает каждый введённый символ с соответствующим символом исходного текста.
4. Если символ введён правильно, пользователь может перейти к следующему символу.
5. Если символ введён неправильно, приложение не должно засчитывать его и разрешать продвижение дальше.
6. Следующие символы не должны приниматься, пока текущая позиция не будет введена правильно.
7. Регистр символов должен учитываться.
8. Пробелы и знаки препинания также должны проверяться.
9. После ввода последнего символа тренировка завершается.

Необходимо предусмотреть визуальное отображение прогресса печати.


7. Подсчёт скорости и ошибок

Скорость печати измеряется в символах в минуту (CPM).

Для этого необходимо:

1. Запустить таймер при начале печати.
2. Зафиксировать время завершения тренировки.
3. Вычислить продолжительность тренировки в минутах.
4. Определить количество правильно напечатанных символов.
5. Вычислить скорость печати.

Формула:

Скорость печати = количество правильно напечатанных символов / время в минутах.

Также необходимо подсчитывать количество неправильных попыток ввода.

Результаты должны отображаться пользователю после завершения тренировки.

8. Сохранение результатов

После завершения каждой тренировки приложение должно сохранять результат в таблицу "results".

Сохранять:

- Скорость печати.
- Количество ошибок.
- Уровень сложности.
- Язык тренировочного текста.
- Дату и время завершения.

Необходимо обеспечить сохранение результатов даже после закрытия приложения.


9. Раздел статистики

Разработать отдельный раздел для просмотра результатов предыдущих тренировок.

Необходимо реализовать:

- Отображение сохранённых результатов.
- Просмотр скорости печати.
- Просмотр количества ошибок.
- Просмотр уровня сложности.
- Просмотр даты тренировки.
- График изменения скорости печати.

График должен отображать изменение результатов пользователя с течением времени.

Для получения данных использовать SQL-запросы к таблице "results".


10. Настройки приложения

Разработать отдельный раздел настроек.

10.1. Язык интерфейса

Предусмотреть два языка:

- Русский.
- Английский.

При переключении языка должны изменяться все надписи, кнопки, названия разделов и системные сообщения приложения.

10.2. Язык тренировочных текстов

Предусмотреть возможность выбора:

- Русского.
- Английского.

Язык тренировочного текста должен быть независим от языка интерфейса.

Например, пользователь может использовать русский интерфейс и тренироваться на английских текстах.

10.3. Темы оформления

Предусмотреть две темы:

- Светлая.
- Тёмная.

При переключении темы должно изменяться оформление всех основных элементов интерфейса.


11. Раздел «О программе»

Создать отдельный раздел с информацией о приложении.

В нём указать:

- Название приложения.
- Назначение программы.
- Использованные технологии.
- Информацию о разработчике.

- Подготовить проект к демонстрации.


13. Требования к готовому приложению

Готовое приложение должно:

1. Корректно запускаться без ошибок.
2. Загружать тексты из базы данных.
3. Выдавать случайные тексты с учётом выбранных настроек.
4. Правильно проверять каждый введённый символ.
5. Не позволять обходить проверку неправильных символов.
6. Корректно вычислять скорость печати.
7. Сохранять результаты тренировок.
8. Отображать историю и график прогресса.
9. Поддерживать два языка интерфейса и два языка тренировочных текстов.
10. Поддерживать светлую и тёмную темы.

Итоговая цель: создать полноценное настольное приложение TypingTrainer, позволяющее пользователю тренировать скорость и точность печати, а также отслеживать собственный прогресс.
